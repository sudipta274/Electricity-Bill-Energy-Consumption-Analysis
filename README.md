# Electricity-Bill-Energy-Consumption-Analysis
This project focuses on analyzing electricity consumption and billing patterns using MS Excel. The dataset was cleaned and transformed to perform detailed analysis through PivotTables, charts, KPIs, slicers, and an interactive dashboard.
## Overview
This project analyzes electricity consumption and billing patterns using MS Excel. The project includes data cleaning, KPI analysis, PivotTables, charts, slicers, and an interactive dashboard.

## Features
- Data Cleaning
- KPI Indicators
- Pivot Tables
- Interactive Dashboard
- Charts & Graphs
- Slicers

## Tools Used
- MS Excel
- Pivot Tables
- Charts
- Slicers
